# PLC-Based VFD Motor Control System

## Overview

This project demonstrates VFD control using an Allen-Bradley PLC and a 3-phase induction motor.

The system was implemented on a physical PLC trainer setup and tested through ladder logic programming.

## Hardware

- Allen-Bradley PLC Trainer
- Variable Frequency Drive (VFD)
- 3-Phase Induction Motor
- Control panel
- Digital input/output interface

## Software

- Allen-Bradley PLC programming software
- Ladder Logic

## Working Principle

The PLC receives control inputs from the trainer panel. The programmed ladder logic processes these inputs and provides control signals for the VFD.

The VFD controls the operation of the connected 3-phase induction motor.
